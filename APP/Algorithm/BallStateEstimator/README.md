# BallStateEstimator

该模块是无MCU/RTOS依赖的三状态固定滞后Kalman估计器，当前用于滚球闭环。状态为球位置
`x`、球速度`v`和模型残差等效加速度`b`。实心球滚动模型是：

```text
kappa = 1/(1 + I/(mR^2)) = 5/7
a_model = -kappa * (g*sin(theta_rod) + a_fwd*cos(theta_rod))
xdot = v
vdot = a_model + b + w_a
bdot = w_b
z_VIS = x + n
```

这里`x>0`和车辆前向同为车头方向，`theta>0`表示车头执行端升高；因此车辆
向前加速的惯性项和正杆角的重力项都使球沿`-x`运动，平衡前馈必须给负杆角。

估计器使用定长128个历史快照，在1 ms周期下覆盖约127 ms。延迟VIS在对应历史
时刻完成标量位置校正，然后按历史杆角/底盘加速度重放至当前。创新使用
`nu^2/S <= gate_sigma^2`门控；超限观测只计数，不修改状态。
连续白加速度噪声密度`q_a`离散为`Qxx=q_a*dt^3/3`、`Qxv=q_a*dt^2/2`、
`Qvv=q_a*dt`，因此VIS处于两快照之间时可拆分时间步而不改变统计含义。

`a_fwd`以车辆向前为正，可来自G3519规划量或ICM实测融合。启用前必须确认相机、杆角和
底盘加速度三条极性，並由原始VIS、创新/NIS、协方差、偏置`b`和原始输入日志整定
`Q/R`。滤波曲线平滑不等于模型正确。
