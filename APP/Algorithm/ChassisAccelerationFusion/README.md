# ChassisAccelerationFusion

该模块是无MCU/RTOS依赖的三状态线性Kalman滤波器，默认不参与产品控制。状态为底盘实际纵向速度`v`、实际纵向加速度`a`和IMU纵向加速度零偏`b_imu`：

```text
X = [v, a, b_imu]
a_dot = (k_a*a_plan_delayed-a)/tau_a + w_a
v_dot = a + w_v
b_imu(k+1) = b_imu(k) + w_b
z_wheel = v + n_v
z_imu = a + b_imu + n_a
a_used = a
```

规划加速度经过纯延迟和一阶执行响应产生500 Hz预测；`ACC_MEAS`中的实际轮速和经过安装轴变换、姿态/重力补偿、零偏初校及抗振滤波的纵向IMU加速度，只在新帧到达时校正。轮速作为速度观测直接使用，不先差分成高噪声加速度。

可信门要求轮速与IMU各自达到最少接受次数、两者均新鲜且`P(a,a)`低于阈值。任一条件不满足时上层必须退回原规划ACC。该退回只决定模型输入，不自动失能电机。

当前配置值是无实车IMU/轮速日志时的保守预测值，接口和单元测试可用，但噪声方差、过程噪声、固定延迟、极性和可信阈值必须用原始日志重新整定。
