# RodAngleMap

本模块保存一个实测、严格单调的机构运动分支，并在相邻节点间做线性插值。它同时提供
`raw -> 杆角`和`杆角 -> raw`，查询超出实测端点时返回失败，不做外推。

当前11点来自2026-07-30向上扫描：QD4310 raw从58499减到53577时，双IMU/CH12示值从
20.640°增到25.450°。初始化在此前确认的机械参考`raw=54379`处插值得到24.6164°并相减，
因此输出是相对该旧零点的杆角，范围约`-3.9764°..+0.8336°`。常量安装偏置不会进入相对
命令，但这不证明CH12是真水平绝对角。

当前只有向上分支。正常滚球会换向，所以下行回差、静摩擦和负载变形仍不在本模块内补偿；
未取得同节点下行实测数据前不得复制、镜像或推算第二张表。
