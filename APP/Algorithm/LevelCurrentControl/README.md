# LevelCurrentControl

本模块是无 MCU、CAN、QD4310 和 RTOS 依赖的纯算法。Gateway 启动时从
`config/core_config.h` 载入固定的单圈绝对编码器机械水平零点，之后把当前绝对角换算成
`-180..180°` 相对角，处理编码器 `0/360°` 回绕。

控制结构固定为“绝对角度外环 → QD4310 `CURRENT` 电流命令”，不调用电机内部
`ANGLE` 位置模式。算法沿用旧工程 `pitch_hold_controller`：角度 P、误差区内积分 I、
转速反馈阻尼 D，并依次执行误差限幅、死区、积分限幅、电流限幅和机械硬角限位。
首轮实机发现 `P=0.010 A/deg` 时约4.54°偏差只产生约0.043 A，刚度不足；DBG确认
`P=0.017 A/deg`在约5.394°偏差时产生约0.088 A。随后`P=0.030`的0.8 s短测把raw从约
59091拉到55023，但在目标54379附近仍需约0.09～0.10 A承重；停止后机构回落到59093。
因此Task3沿用2026-07-31 08:51参数：P取`0.014 A/deg`，使用`-0.072 A`静态重力前馈，
转速阻尼D保持`0.0010 A/rpm`，电流上限仍为0.30 A。Task2/4/5/6恢复原参数：
`P/I/D=0.014/0.0020/0.0010`、承重前馈`-0.090 A`、死区`0.05°`、积分限幅`0.020 A`。
目标点保留完整承重前馈；当位置误差请求与前馈相反的方向时，前馈在当前参数组的死区内
线性释放，并在P项开始作用前降为0，
避免静态前馈压过下行闭环请求。合成电流仍统一经过电流限幅和机械保护。
Task3的KI为`0.0010 A/(deg*s)`，积分仅在`|误差|<=2°`时工作且限幅到`0.010 A`；
其他赛题的KI和积分限幅分别为`0.0020 A/(deg*s)`和`0.020 A`。两组参数均不扩大最终
`0.30 A`电流上限，也不增加转速滤波或最终电流限斜率。
最新VOFA最后连续使能段末100帧raw均为54379、标准差0、转速0；按用户确认将54379
设为固定机械参考零点。`raw=54329`相对它约为电机角`-0.275°`，但经机构实测表换算为
杆角约`+0.061°`；本模块只处理前一种电机角域。

所有实机可调初值都由 `config/core_config.h` 的 `GATEWAY_LEVEL_*` 提供。极性和增益必须
先用低风险机构确认方向，再逐步整定。两个目标API的状态语义不同：

- `Algorithm_LevelCurrentControl_SetTargetDeg()`用于离散标定换点，更新目标并清积分；
- `Algorithm_LevelCurrentControl_SetTrackingTargetDeg()`用于1 kHz调度下的滚球连续目标，只更新
  目标，不反复清积分；
- `Algorithm_LevelCurrentControl_SetTuning()`只切换现有PID参数组；参数真正变化时清积分，
  重复应用同一组参数不扰动运行状态。

正常目标由Gateway把杆角经实测表逆查成raw后换算得到，不再是固定`-0.275°`。本模块的
`±85°`目标限制属于电机相对角；当前杆角实际可用范围还受单向实测表约
`-3.9764°..+0.8336°`限制。
