# LevelCurrentControl

本模块是无 MCU、CAN、QD4310 和 RTOS 依赖的纯算法。Gateway 启动时从
`config/core_config.h` 载入固定的单圈绝对编码器机械水平零点，之后把当前绝对角换算成
`-180..180°` 相对角，处理编码器 `0/360°` 回绕。

控制结构固定为“绝对角度外环 → QD4310 `CURRENT` 电流命令”，不调用电机内部
`ANGLE` 位置模式。算法沿用旧工程 `pitch_hold_controller`：角度 P、误差区内积分 I、
转速反馈阻尼 D，并依次执行误差限幅、死区、积分限幅、电流限幅和机械硬角限位。
首轮实机发现 `P=0.010 A/deg` 时约4.54°偏差只产生约0.043 A，刚度不足；当前模板将
P提高到 `0.015 A/deg`、转速阻尼D提高到 `0.0010 A/rpm`，电流上限仍为0.30 A。
`P=0.030/0.020 A/deg` 的实机试验均因振动明显已否决；本轮保持KD不变以单独观察P。
为改善零点附近的稳态误差，KI由 `0.0002` 提高到 `0.0010 A/(deg*s)`；积分仅在
`|误差|<=1°` 时工作且仍限幅到 `0.010 A`，不会扩大最终 `0.30 A` 电流上限。
三份标定记录的中位数均值为55207，相对固定零点55183高24计数；当前目标因此设置为
相对机械零点 `+0.13°`，不修改绝对零点本身。

所有实机可调初值都由 `config/core_config.h` 的 `GATEWAY_LEVEL_*` 提供。默认目标为固定
机械零点附近的 `+0.13°`；极性和增益必须先用悬空/低风险机构确认方向，再逐步整定。
